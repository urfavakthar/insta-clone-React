# Simple_InstaClone
# Frontend: React.js
  *** A full-featured social media web app inspired by Instagram, built with React.js and integrated with a mock backend using JSON Server / REST APIs. This project demonstrates modern frontend development skills, component-based architecture, and dynamic data handling.**

# Key Features
1. Dynamic Feed & Posts

 *** Supports images, carousels, and reels**
 *** Interactive likes, captions, hashtags, and comments**
 *** Seamless video and image playback**

2. Stories

 *** View image and video stories**
 *** Gradient borders with smooth responsive layout**

3. Profile Management

*** Edit user profile information**
*** Display and manage followers dynamically**

4. Suggestions & Follow System

*** Real-time follow/unfollow functionality**
*** Personalized suggestions with interactive UI**

5. Responsive Sidebar Navigation

*** Top & bottom menu with React Router-based navigation**
*** Fully responsive for desktop and tablet views**

6. Reusable Component Architecture

*** Modular components for Posts, Stories, Profile, Sidebar, Suggestions**
*** Easy to scale and maintain**

# Tech Stack
1. Frontend: React.js, React Router, Axios
2. Backend: JSON Server (mock REST API)
3. Styling: CSS (Flexbox, gradient borders, responsive design)
4. Media Handling: Video, image, and carousel support

# Highlights
1. Clean, modular architecture for scalability
2. Efficient state management using React Hooks (useState, useEffect)
3. Handles asynchronous API calls with proper error handling
4. Fully responsive design with interactive user experience
5. Dynamic UI updates for posts, stories, followers, and suggestions

# Skills Demonstrated
1. React.js & Hooks
2. REST API Integration & Async Programming
2. Component-based architecture & Reusable UI
3. Responsive Design & Media Handling  
5. Frontend-backend interaction & state synchronization
